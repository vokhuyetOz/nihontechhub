# nihontechhub-web

## Description

- This boilerplate is a minimal, yet powerful, starter template built with Next.js, ShadCN, and TailwindCSS. It provides a modern development environment for building scalable and performant web applications with ease.

- Next.js: A robust React framework that offers optimized rendering, server-side rendering (SSR), static site generation (SSG), API routes, and more.
- ShadCN: A utility-first UI component library that integrates seamlessly with TailwindCSS, enabling rapid UI development with pre-designed, accessible components.
- TailwindCSS: A highly customizable CSS framework for building beautiful, responsive designs directly within your HTML without writing custom CSS.

## Installation

To install and run nihontechhub-web locally on your machine, follow these steps:

1. **Clone the repository**:

   ```bash
   git clone https://git.rabiloo.net/mobile/nextjs/nextjs-shadcn-tailwind nihontechhub-web
   ```

2. **Navigate into the project directory**:

   ```bash
    cd nihontechhub-web
   ```

3. **Clone the repository**:

   ```bash
   npm install
   ```

   or

   ```bash
   yarn install
   ```

4. **Start the development server**:

   ```bash
   npm run dev
   ```

   or

   ```bash
   yarn run dev
   ```

## Features

- Next.js for server-side rendering (SSR), static site generation (SSG), and optimized production builds.
- ShadCN for a well-crafted component library integrated with TailwindCSS for quick, accessible UI building.
- TailwindCSS for utility-first styling, offering rapid design and flexibility.
- TypeScript for static typing and improving the developer experience.
- Pre-configured dark/light theme support.
- Responsive and mobile-friendly layout out of the box.
- Easily customizable and scalable for new projects.
